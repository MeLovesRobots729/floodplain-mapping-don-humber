# Data Sources

This folder contains data sources and metadata for the floodplain mapping project.

## Data Files

- `station_locations.csv` - TRCA precipitation gauge locations and mean annual values
- `data_sources.txt` - List of all data sources with links

## Data Source Links

- **NASADEM 30m DEM**: https://doi.org/10.5069/G93T9FD9
- **TRCA Floodplain Data**: https://data.trca.ca/
- **TRCA Precipitation Data**: https://data.trca.ca/dataset/precipitation
- **TRCA River Network**: https://data.trca.ca/

## Important Notes

- Full raster datasets (GeoTIFFs) are not included in this repository due to file size limits
- To reproduce this analysis, download the data from the sources above
- See the README.md in the root directory for instructions
